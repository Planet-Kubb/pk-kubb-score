# Planet Kubb Score

A static website for the Planet Kubb Notation (docs, the printable scoresheet, and a stats
calculator), plus the archive it is built on: every turn-by-turn Kubb game recorded on the Planet Kubb wiki (wiki.planetkubb.com, 2011-2015),
written out as plain text in the Kubb Notation that the wiki defined. The files are meant to be
read by a parser that produces game and player statistics.

## Website

`site/` is the website: plain HTML, one stylesheet, vanilla JS modules, no build step. Serve it
from its root (`cd site && python3 -m http.server`); pages use root-relative paths.

- `index.html`, `notation/`, `spec/` (grammar), `scoresheet/`, `stats/`.
- `assets/kubb.js`: the notation parser, game-state simulator and stats. It has no dependencies
  and also runs in Node, so `node tools/check-parser.mjs` runs it over every archived game
  (`-v` lists each warning).
- `assets/stats.js`: the Stats page UI. It accepts `?game=<id>` for an archived game and
  `#n=<url-encoded notation>` for pasted text.
- `data/games.json` and `scoresheet/*.pdf|png` are generated by `tools/build-site-data.py`.
  Rerun it after changing `games/`.

The notation page is adapted from planetkubb.com's live notation page (saved in
`sources/planetkubb.com/`), rewritten as lists. Its example game uses `A` for the 2012 `BA`/`MA`
markers and `jt:` for the inkasts the original wrote as `j:`. Scoresheet v11 (July 2014) is the
current one. planetkubb.com still links v10 + stats.

## Grammar

`grammar/planet-kubb-notation.peggy` is the formal grammar: a parsing expression grammar for
[Peggy](https://peggyjs.org) that defines exactly what valid notation is. It is the source of
truth for the notation's syntax. Game logic (does the inkast match the kubbs knocked down,
should there be an advantage line) is not syntax; `site/assets/kubb.js` checks that by
replaying the game.

- `npm install` once, then `npm run grammar` after editing the grammar. That compiles it into
  `site/assets/notation-parser.js`, copies it to `site/spec/`, and redraws the railroad diagrams
  in `site/spec/index.html` (between the `<!-- diagram:Rule -->` markers).
- `npm test` checks the grammar against all 150 games, the docs' examples and a list of strings
  that must be rejected. It also checks that the grammar and `kubb.js` read every turn the same
  way. 149 games are valid; the Nordic Fest 2012 final, game 3, turn 6 has a real `F-` slip.
- `site/spec/` is the Grammar page: what a grammar is, a live checker, the railroad diagrams,
  and the decisions the grammar settles.

## Layout

- `games/`: 150 games, one file each, named `YYYY-MM-DD-<wiki title>.txt`.
- `scoresheets/`: 42 scanned handwritten scoresheets that match games here (each linked by a
  `[Scoresheet]` header). `scoresheets/blank/` holds the blank sheet designs.
- `docs/Kubb_notation_diagram.png`: the diagram from the wiki's Notation page.
- `sources/planetkubb.com/`: the live notation page (2026-10-02), its 2018 Wayback capture,
  `wp-json-2026-10-02/` (every live post and page from the WordPress REST API, including about 80
  glossary and slang entries from 2017 that the 2016 dump lacks), and the Planet Kubb blog posts about the notation, scoresheet and stats (`posts/`, from the WordPress dump).
- `scoresheets/blank/v11-source/`: the OmniGraffle source for v11. This repo began in 2014 as `Planet-Kubb/scoring`, which held just this file and the v11 PDF (`scoresheets/blank/Planet_Kubb_Scoresheet.pdf`).
- `sources/`: the original wikitext for the Notation and Scoresheet pages and their talk pages,
  plus `deleted/`, two US Nationals 2012 games (Kubbchucks IDP v. Shenanigans) deleted from the
  wiki on 2013-02-06 and recovered from the archive table in the SQL dump.
- `tools/wiki2kubb.py`: regenerates `games/` from
  `~/Projects/mediawiki-archive/wiki.planetkubb.com-Sun-7.xml.gz`. It also writes
  `tools/report.json`, which lists every game's consistency flags (see below).
  `tools/scoresheets.json` maps scoresheet files to games.
- `tools/archive/`: helpers from the original dig: `sqlrows.py` reads tables from a gzipped
  mysqldump without a server, and `tpl.py` parses MediaWiki templates. `AGENTS.md` lists where
  every source dump lives.

## File format

```
[Event "US National Kubb Championship 2012"]
[Location "Eau Claire Soccer Fields"]
[Start "2012-07-15 09:20"]
[End "2012-07-15 09:43"]
[Duration "23m"]
[Team A "Kubb'd"]
[Team A Players "Steve Feathers (f), Stephanie Kidder (s), Dana Oredson (d)"]
[Team B "Kubbsicles"]
[Team B Players "Zachary Brown (z), Mark Blazel (k), Max Sebesta (x)"]
[First "Team A"]
[Win "Team B"]
[Scored by "Tony Hansen"]
[Entered by "Garrickvanburen"]
[Stats "Yes"]
[Scoresheet "scoresheets/Us2012-kubbsicles-kubbd-game1.pdf"]
[Source "https://wiki.planetkubb.com/wiki/Game:..."]

1. 0I d:B d:- s:- s:- f:- f:B
2. 2I z:- k:F x:- k:F z:- k:-
3. 2IRP d:- d:- s:F f:F f:B s:-
...
16. 7I A k:2F k:2F z:2F x:F x:B z:K
```

Headers are PGN-style `[Key "value"]` lines, then a blank line, then one line per turn. A
header is left out when the wiki had no value for it.

| Header | Meaning |
|---|---|
| Event, Location, Surface | As entered on the wiki. Event names are not normalized. |
| Start, End | `YYYY-MM-DD HH:MM` local time, or just the date when no time was entered. |
| Event date | Used instead of Start when the game had no date; the first day of the event, from its Event: page. |
| Duration | Minutes between Start and End. |
| Team A / Team B Players | `Name (id)`, where id is the player prefix used in the turns. |
| First | The team that threw first. The wiki always assumed Team A. Here it comes from the last turn: the team that takes the king is the winner, which tells you who opened. 16 games turned out to start with Team B. |
| Win | `Team A` or `Team B`. |
| Scored by, Entered by | Who kept score and who typed it in. |
| Video, Video offset | YouTube link when the game was scored from video. |
| Stats | The wiki's "Include stats" flag: No meant the game was left out of the wiki's statistics. |
| Player note | Any note attached to a player on the wiki. |

Turn lines follow the wiki's own Notation renderer (the hidden Notation row in Template:Game turn):

```
n. [p:]KUBBS [A] p:BATON p:BATON ... # note
```

- `n.`: turn number. Turns alternate, starting with the `First` team.
- `KUBBS`: the inkast, e.g. `5I2R` (5 kubbs thrown in, 2 rethrown), `2IRP` (2 in, one rethrown, one penalty kubb); a bare `I` is one kubb.
  Turn 1 often has none. A second inkast token appears when two players threw kubbs.
- `A`: the attacking team threw from an advantage line.
- `BATON`: `-` miss, `F`/`nF` field kubbs, `B`/`nB` base kubbs, `FB` combinations, `K` king,
  `=` missed king, `X` unthrown, `!` illegal king hit, `Z` illegal throw.
- `p:`: the player id, present on 107 of the 150 games. Ids are lowercased, with spaces turned into `_`.
- Batons are kept as recorded, with action codes uppercased. A turn can have fewer than six:
  the 2015 games use the 2-4-6 opening (2 batons, then 4, then 6).

The full original definition is in `sources/notation.wiki`.

## Known data issues

`tools/report.json` flags things a parser should handle rather than paper over:

- 23 turns where the kubbs thrown in don't match the kubbs knocked down in the previous
  turn. Some are scoring slips. Others are real events explained in the turn's note, such as a
  field kubb picked up by mistake and thrown back in.
- `F-` on one baton (Nordic Fest 2012 final, game 3, turn 6), and some games that record
  unthrown batons as `-` instead of `X`.
- A 2015 duplicate entry was dropped. The scoring app had written `undefinedF1B` into turn 1 of
  "2015 U.S. National Kub Championship Quarterfinals Game 2"; the correctly spelled page is kept.
